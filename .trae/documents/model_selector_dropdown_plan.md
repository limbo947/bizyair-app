# 模型切换下拉浮层 UI 优化计划

## 研究结论

当前模型切换使用的是水平滚动的卡片式设计（`modelGridContainer` + `ScrollView`），需要改为左上角的下拉浮层交互。

## 修改文件清单

1. `src/screens/HomeScreen.js` - 修改模型切换 UI

## 详细实现步骤

### 1. 修改标题行布局
- 将标题行改为左对齐布局
- 左侧放置模型选择器触发按钮（模型名称 + 下拉箭头 ⌄）
- 移除原有的水平滚动模型卡片区域

### 2. 实现下拉浮层
- 添加 `showModelDropdown` 状态控制浮层显示/隐藏
- 点击模型选择器触发按钮时展开/收起浮层
- 浮层使用绝对定位，悬浮于主内容区上方
- 浮层样式：
  - 白色背景（Colors.card）
  - 圆角（Radius.md）
  - 阴影（Shadows.lg）
  - 包含所有模型列表，以网格或列表形式展示
  - 每个模型项显示图标和名称
  - 当前选中模型高亮显示（主色调）

### 3. 交互逻辑
- 点击模型选择器触发按钮：切换浮层显示状态
- 点击浮层外部区域：关闭浮层
- 点击模型项：选择模型并关闭浮层
- 选择后更新 `modelId` 状态

### 4. 样式规范
- 保持与现有风格一致
- 使用现有的 Colors、Shadows、Radius、Spacing 常量
- 触发按钮样式：
  - 背景色：Colors.bg 或透明
  - 文字：Colors.textPrimary
  - 下拉箭头：Colors.textSecondary
  - 圆角：Radius.sm
  - 内边距：Spacing.sm
- 浮层样式：
  - 最大高度限制，超出可滚动
  - 与触发按钮左对齐
  - 顶部间距：Spacing.sm

### 5. 视觉反馈
- 触发按钮点击时有按压效果（activeOpacity）
- 当前选中模型在浮层中高亮显示
- 模型项有悬停/按压反馈

## 风险与注意事项

- **兼容性**：确保在 Android 上正常工作
- **性能**：浮层显示/隐藏动画流畅
- **最小改动**：只修改必要的代码，保持其他功能不变
- **代码规范**：单文件不超过 300 行，遵循现有代码风格
