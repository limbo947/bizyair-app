## 二. 提交请求

### 1. 请求示例

```javascript
async function submitTask() {
  const url = 'https://api.bizyair.cn/x/v1/modelzoo/tasks/openapi/bza-chat-g3-flash-official/large-language-models';
  const payload = {
    "system_prompt": "你是一位穿越时空的侦探，专门调查那些\n\"看似普通实则细思极恐\"的日常现象。\n\n你的特点：\n- 用侦探推理的方式解构一切看似理所当然的事情\n- 善于从细节中发现被大多数人忽略的荒诞与奇异\n- 语言风格带有一丝黑色幽默，严肃中藏着玩味\n- 每次推理都会抵达一个让人意想不到的结论",
    "user_prompt": "请调查以下这个\"案件\"：\n\n案件名称：人类每天早上为什么要喝一杯\n名为\"咖啡\"的苦涩黑色液体才能正常运转？\n\n请以侦探调查报告的格式输出，包含：\n- 案件背景与现场还原\n- 嫌疑人排查（生理、心理、社会层面）\n- 关键证据分析\n- 侦探的最终推断\n- 留给读者的灵魂一问\n\n要求推理严密但充满反转，结论出人意料，\n让读者读完之后陷入对自己日常行为的深度怀疑。",
    "max_tokens": 32768,
    "temperature": 1,
    "enable_thinking": true,
    "enable_search": true
  };

  try {
    const response = await fetch(url, {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'Authorization': 'Bearer ${BIZYAIR_API_KEY}'
      },
      body: JSON.stringify(payload)
    });

    const result = await response.json();
    console.log('Success:', result);
  } catch (error) {
    console.error('Error:', error);
  }
}

submitTask();
```

### 2. 请求参数说明

| 参数名 | 类型 | 必填 | 说明 |
| :--- | :--- | :--- | :--- |
| system_prompt | string | 是 | 文本长度限制：1 - 2500<br/>系统提示词 |
| user_prompt | string | 是 | 文本长度限制：1 - 2500<br/>用户提示词 |
| max_tokens | number | 是 | 取值范围：1 ~ 65536<br/>生成文本最大长度（token） |
| temperature | number | 是 | 取值范围：0 ~ 2<br/>步进：0.01<br/>采样温度 |
| enable_thinking | boolean | 否 | 启用思考 |
| enable_search | boolean | 否 | 启用搜索 |

> 为保护您的业务敏感信息（如 prompt 设计等），我们支持对 API 调用记录中的指定字段进行脱敏处理。脱敏后的字段在查询调用记录时将显示为 `[调用方要求隐藏]`，但不影响实际请求的执行和计费准确性。
>
> **使用方法**：在请求头中携带 `X-BizyAir-Log-Mask-Fields`，指定需要脱敏的字段，多个字段用英文逗号分隔。
>
> ```http
> Content-Type: application/json
> Authorization: Bearer ${BIZYAIR_API_KEY}
> X-BizyAir-Log-Mask-Fields: prompt, image_urls
> ```

### 3. 响应字段说明

| 参数名 | 类型 | 说明 |
| :--- | :--- | :--- |
| request_id | string | 请求ID，用于后续查询任务状态。 |
| status | string | 任务状态，可能的值为：Pending（排队中）、Running（运行中）、Saving（转存中）、Success（完成）、Failed（失败）。 |
| message | string | 任务状态为 Failed 时，错误的具体信息。 |
| executed_at | string | 任务开始运行的时间。 |
| ended_at | string | 当任务成功或失败时，任务结束的时间。 |
| outputs | array | 生成结果（非“完成”状态时，为null或[]）。 |
| outputs.texts | array | 文本类输出结果。 |
